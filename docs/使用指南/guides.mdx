# 🚀 快速入门

欢迎开始使用本产品。以下是基础环境准备和安装步骤。

## 环境要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 / macOS 10.13 | Windows 11 / macOS 12+ |
| 内存   | 4GB RAM  | 8GB RAM  |
| 存储空间 | 2GB 可用 | 5GB 可用 |

## 安装依赖

请确保已安装以下软件：

- [Node.js](https://nodejs.org/) v16+
- [Git](https://git-scm.com/) 2.20+

<Tabs>
  <TabItem value="windows" label="Windows">
    在 Windows 上推荐使用 WSL 或 PowerShell。
  </TabItem>
  <TabItem value="macos" label="macOS">
    使用 Homebrew 安装：
    ```bash
    brew install node git
    ```
  </TabItem>
</Tabs>

:::tip 验证安装
运行以下命令检查是否安装成功：
```bash
node --version
git --version
