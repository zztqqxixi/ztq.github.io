配置方法

核心配置​

项目使用 build.gradle 文件进行核心配置，用户可根据需求自定义节点参数、网络设置和数据库集成等选项。

节点定义​

在 build.gradle 中，你可以自定义节点参数，具体配置如下：

ext.nodeConfigurations = [
  [ name: "O=Notary,L=London,C=GB", notary: true, p2pPort: 10002, ... ],
  [ name: "O=PartyA,L=London,C=GB", p2pPort: 10005, ... ],
  // 按需添加新节点
]

其中，关键参数包括 p2pPort（节点通信端口）、rpcPort（RPC 端口）、dbUser（数据库用户）等，这些参数属于基本参数。

网络配置​

项目能够自动获取本地 IP 并应用于节点，相关配置如下：

def nodeIpAddress = getLocalIpAddress() // 自动检测非回环IP

p2pAddress "${nodeIpAddress}:${config.p2pPort}"

通过这种自动获取和配置的方式，简化了网络设置，确保节点之间能够顺利进行通信。

数据库集成（需手动启用）​

若要启用数据库集成功能，需取消注释 setupDatabase 任务实现。启用后，将实现以下功能：

  • 自动创建 corda_db 数据库
  • 为每个节点生成独立数据库用户
  • 授予完整的 Schema 操作权限

这一功能为项目的数据存储和管理提供了便利，同时保证了各节点数据的独立性和安全性。

注意：目前暂时不能通过脚本进行授权，需要自己手动对数据库和用户进行授权。

集成组件说明​

1. setup_corda_db.sql 脚本​

路径: cordapp-example/setup_corda_db.sql

功能: Windows 系统"零配置"启动 PostgreSQL

首次执行行为:

  • 在 %USERPROFILE%\psql\data 初始化数据库实例
  • 创建与当前 Windows 用户名相同的超级用户（密码 890415）

非首次执行行为:

  • 检测 5432 端口占用情况（若被占用则直接退出）
  • 日志输出到 %USERPROFILE%\psql\logs\postgres.log

2. start_postgres.ps1 脚本​

路径: cordapp-example/start_postgres.ps1

功能: 幂等性准备 CordApp 数据库环境

DataDir和LogDir这两个路径需要根据安装的psql路径来具体修改:

# 参数默认值
$DataDir = "$env:USERPROFILE\psql\data"
$LogDir  = "$env:USERPROFILE\psql\logs"
$Port = 5432
$UserName = (whoami)
$Password = "890415"

3. Gradle任务配置​

3.1 任务概述​

在build.gradle中定义了三个关键任务，用于将数据库操作整合到Gradle构建生命周期：

  • startPostgresIfNeeded: 自动启动PostgreSQL
  • setupCordaDb: 自动建库建用户
  • deployNodes: 最终部署节点，依赖于setupCordaDb

3.2 startPostgresIfNeeded任务​

作用: 自动启动PostgreSQL服务

行为说明​

  • Windows系统: 调用start_postgres.ps1脚本启动PostgreSQL
  • 非Windows系统: 仅打印跳过信息，不执行任何操作

关键特性​

  • 幂等性设计：如果5432端口已被占用（PostgreSQL已运行），则不会重复启动
  • 无需手动干预，完全集成到构建流程

3.3 setupCordaDb任务​

作用: 自动创建数据库和用户

依赖关系​

dependsOn 'startPostgresIfNeeded'

确保数据库已启动后才执行后续操作。

执行流程​

  1. 使用当前系统用户名和超级用户密码890415登录PostgreSQL
  2. 执行setup_corda_db.sql脚本
  3. 完成数据库和用户的创建与配置

3.4 deployNodes任务​

作用: 部署Corda节点

依赖关系​

deployNodes.dependsOn 'setupCordaDb'

确保在节点部署前，PostgreSQL数据库与用户已完全准备就绪。

执行时机​

只有在以下条件满足后才会执行：

  • PostgreSQL服务已启动
  • 必要的数据库（corda_party_a、corda_party_b）已创建
  • 数据库用户（user_a、user_b）已配置并授权

前提准备​

  1. 已安装PostgreSQL并将bin目录加入环境变量（使用pg_ctl --version和psql --version验证）

  2. PowerShell正常运行

  3. 确认项目目录（cordapp-example的根目录下）包含以下文件：

    • setup_corda_db.sql
    • start_postgres.ps1
    • build.gradle

  4. 确保5432端口未被占用（若占用需停止服务或修改脚本中的$Port参数）

  5. 在cordapp-example目录执行：

    .\gradlew deployNodes //节点运行
    .\runnodes.bat //测试

注意事项​

  1. 节点运行时如果进度长时间卡在83%，是因为 Gradle 把 pg_ctl start 当成“子进程”在等它结束，ctrl+c结束进程重新.\gradlew deployNodes即可（经过修改之后测试已经不会出现这种情况，如果出现，可以试一下）
  2. 如果想修改psql超级用户密码，需要在第一次运行.\gradlew deployNodes之前对这两个脚本中的内容进行修改。
