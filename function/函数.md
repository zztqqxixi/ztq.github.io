## 2. 矩阵与数组

### 2.1 创建矩阵
```matlab
% 创建3x3单位矩阵
A = eye(3); 

% 生成对角矩阵
B = diag([1 2 3]);

% 水平拼接矩阵
C = horzcat(A, B);
```

### 2.2 矩阵运算
| 函数        | 说明                  | 示例                     |
|-------------|-----------------------|--------------------------|
| `inv`       | 矩阵求逆              | `inv(A)`                 |
| `eig`       | 特征值分解            | `[V,D] = eig(A)`         |
| `norm`      | 矩阵/向量范数         | `norm(A, 'fro')`         |

> 3. 使用 `which 函数名` 查看函数路径
