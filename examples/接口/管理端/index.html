管理端

1. 账户认证接口​

接口功能​

处理管理用户的登录、token刷新、权限验证等认证相关操作。与政府模块完全一致。

请求方法​

POST

请求地址​

/api/admin/auth

请求参数​

字段名字段说明字段类型是否必须
action操作类型string是
username用户名string否
password密码string否
tokenJWT令牌string否

请求示例​

{
  "action": "login", 
  "username": "admin_user",
  "password": "encrypted_str", 
  "token": "jwt_token"
}

返回值​

json_ret（包含新的JWT令牌和用户信息）

响应示例​

{
  "token": "new_jwt",
  "user": {
    "role": "administrator",
    "permissions": ["user_manage", "data_access", "system_config"]
  }
}

特点​

所有管理端请求使用该接口获取的token进行身份验证。

2. 万能数据管理接口​

接口功能​

统一管理各类数据实体，支持查询、新增、更新、删除等操作。

请求方法​

POST

请求地址​

/api/admin/entities

请求参数​

字段名字段说明字段类型是否必须
entity操作对象类型string是
action操作类型string是
filters查询条件object否
data修改时的数据object否

请求示例​

{
  "entity": "user", 
  "action": "query", 
  "filters": {}, 
  "data": {}
}

返回值​

json_ret（包含操作结果和数据）

响应统一格式​

{
  "success": true,
  "data": [], 
  "pagination": {}
}

3. 日志与监控接口​

接口功能​

查询系统操作日志和预警信息，用于监控系统运行状态。

请求方法​

POST

请求地址​

/api/admin/logs

请求参数​

字段名字段说明字段类型是否必须
type日志类型string是
filters过滤条件object否

请求示例​

{
  "type": "operation", 
  "filters": {
    "time_range": ["2024-01-01", "2024-01-31"],
    "level": 5
  }
}

返回值​

json_ret（包含日志列表）

响应统一格式​

{
  "logs": [
    {
      "timestamp": "2024-01-15T14:30:00",
      "operator": "admin1",
      "details": "修改用户123权限"
    }
  ]
}

前端调用示例​

封装万能管理API​

// 封装万能管理API
class AdminService {
  constructor(token) {
    this.token = token;
  }

  async manage(entity, action, params = {}) {
    const res = await fetch('/api/admin/entities', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ entity, action, ...params })
    });
    return await res.json();
  }

  // 查询活跃农户
  async getActiveFarmers(page = 1) {
    return this.manage('user', 'query', {
      filters: { type: 'farmer', status: 'active' },
      pagination: { page }
    });
  }

  // 更新农田信息
  async updateFarm(farmId, newData) {
    return this.manage('farm', 'update', {
      data: { id: farmId, ...newData }
    });
  }
}
