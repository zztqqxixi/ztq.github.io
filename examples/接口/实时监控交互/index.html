实时监控交互

1. 获取农田环境信息接口​

接口功能​

以 JSON 格式提交环境数据查询请求，返回指定农田的综合环境监测结果（整合所有传感器采集的环境类数据后的汇总信息）。后端会将整合后的环境数据以类短信格式的消息推送至 APP 内消息中心，同时支持前端主动查询获取相同信息。

请求方法​

POST

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
farm_id农田唯一标识 IDint是
data_type环境数据类型筛选（可选）string否
push_channel推送通道（固定值："app_message"）string是
push_frequency推送频率（单位：分钟，可选）int否
push_threshold环境数据推送阈值条件（可选）json否

请求示例​

{
  "type": "get_environment_info",
  "token": "用户令牌",
  "farm_id": 123,
  "data_type": "all",
  "push_channel": "app_message",
  "push_frequency": 10,
  "push_threshold": {
    "temperature": {
      "min": 10,
      "max": 35
    }
  }
}

后端处理流程​

  1. 验证 token 有效性及参数合法性（如 farm_id 不为空、push_channel 值正确）
  2. 封装 JSON 请求数据包
  3. 通过 POST 方法发送至后端接口
  4. 后端处理流程：
    • 整合指定农田所有传感器的环境类数据（如空气温湿度、土壤参数等）
    • 生成综合环境评估结果
    • 将汇总信息转换为类短信格式的 APP 内消息
    • 根据 push_frequency 和 push_threshold 配置，通过 APP 内消息通道推送至用户 APP 保存 APP 内消息发送记录
  5. 前端接收后端返回的整合环境数据及消息推送状态信息
  6. 解析数据并更新环境监测仪表盘，同时显示最近环境相关的 APP 内消息通知记录

2. 获取农田作物信息接口​

接口功能​

以 JSON 格式提交作物数据查询请求，返回指定农田的作物生长状态信息（整合传感器采集的与作物直接相关的数据后的汇总信息，如生长周期、病虫害风险等）。后端支持将作物信息以类短信格式推送至 APP 内消息中心，同时允许前端主动查询。

请求方法​

POST

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
farm_id农田唯一标识 IDint是
data_type作物数据类型筛选（可选）string否
push_channel推送通道（固定值："app_message"）string是
push_frequency推送频率（单位：分钟，可选）int否
push_threshold作物数据推送阈值条件（可选）json否

请求示例​

{
  "type": "get_crop_info",
  "token": "用户令牌",
  "farm_id": 123,
  "data_type": "all",
  "push_channel": "app_message",
  "push_frequency": 30,
  "push_threshold": {
    "pest_risk_level": {
      "min": 0,
      "max": 2
    }
  }
}

后端处理流程​

  1. 验证 token 有效性及参数合法性（如 farm_id 不为空、push_channel 值正确）
  2. 封装 JSON 请求数据包
  3. 通过 POST 方法发送至后端接口
  4. 后端处理流程：
    • 整合指定农田与作物相关的传感器数据及生长记录（如生长阶段、叶片状态、病虫害监测数据等）
    • 生成作物生长状态评估结果（如生长健康度、预估成熟时间、病虫害风险提示等）
    • 将汇总信息转换为类短信格式的 APP 内消息
    • 根据 push_frequency 和 push_threshold 配置，通过 APP 内消息通道推送至用户 APP 保存 APP 内消息发送记录
  5. 前端接收后端返回的整合作物数据及消息推送状态信息
  6. 解析数据并更新作物生长状态展示页面，同时显示最近作物相关的 APP 内消息通知记录
