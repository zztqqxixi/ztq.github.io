AI交互

1. 生成农业方案​

接口功能​

此接口以 JSON 格式提交方案生成请求，返回 AI 生成的定制化农业方案。

请求方法​

POST

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
farm_id农田唯一标识IDint是
demand_type需求类型string是
description描述（可选）string否
image_url图片链接（可选）string否

请求示例​

{
  "type": "generate_ai_scheme",
  "token": "",
  "farm_id": "",
  "demand_type": "",
  "description": "",
  "image_url": ""
}

返回值​

json_ret（包含方案详情、操作步骤、建议等）

接口执行流程​

  1. 验证 token 有效性及参数完整性
  2. 封装 JSON 数据包
  3. 通过 POST 方法发送数据包到后端
  4. 接收后端返回的 AI 方案数据
  5. 解析数据并展示方案详情页面

2. 农业知识查询​

接口功能​

此接口以 JSON 格式提交知识查询请求，返回 AI 的知识解答内容。

请求方法​

POST

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
question用户问题string是

请求示例​

{
  "type": "agri_knowledge_query",
  "token": "",
  "question": ""
}

返回值​

json_ret（包含知识回答、相关扩展知识链接）

接口执行流程​

  1. 验证 token 有效性及问题合法性
  2. 封装 JSON 数据包
  3. 通过 POST 方法发送数据包到后端
  4. 接收后端返回的知识解答
  5. 解析数据并展示回答内容

3. AI 天气查询接口​

接口功能​

用户通过 APP 内 AI 模块提交天气查询请求（如语音或文字询问 "今天天气怎么样"），AI 解析问题后返回指定地区的今日天气信息，支持结合用户绑定的农田位置自动定位查询。

请求方法​

POST

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
question天气查询问题string是
farm_id用户绑定的农田ID（可选）int否

请求示例​

{
  "type": "ai_weather_query",
  "token": "",
  "question": "今天天气怎么样",
  "farm_id": 123
}

返回值​

json_ret（包含 AI 解析的天气信息，如日期、地区、温度、天气状况、风力风向、湿度等）

后端处理流程​

  1. 验证 token 有效性及参数合法性（question 不为空）
  2. 封装 JSON 请求数据包
  3. 通过 POST 方法发送至后端接口
  4. 后端处理流程：
    • AI 解析 question，提取查询的地区（若未明确，默认使用 farm_id 对应的农田所在地区）和时间（默认 "今天"）
    • 调用气象数据接口获取对应地区的今日天气数据
    • AI 将天气数据转换为自然语言回答（如 "您绑定的农田所在地区今日晴，气温 25-32℃，南风 2 级，湿度 45%"）
  5. 前端接收后端返回的 AI 回答内容，展示在 APP 的 AI 交互界面

4. 整合型 AI 交互接口（含知识查询与图片识别）​

接口功能​

统一处理用户提交的农业知识查询、图片识别请求，返回整合后的 AI 分析结果。支持文字提问结合图片补充信息，适用于作物病虫害识别、农技问题解答等场景。

请求方法​

POST

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
question用户问题string是
image_url图片资源地址（可选）string否
data_type结果类型筛选（可选）string否

请求示例​

{
  "type": "ai_agri_interact",
  "token": "用户令牌",
  "question": "小麦叶片发黄是什么原因？",
  "image_url": "https://example.com/wheat_leaf.jpg",
  "data_type": "all"
}

返回值​

json_ret：包含以下内容

  • 知识回答：针对问题的文字解释、相关农技知识
  • 图片分析结果（若有图片）：识别结论（如 "疑似小麦锈病"）、置信度、防治建议
  • 扩展链接：相关农业知识库或案例

后端处理流程​

  1. 验证token有效性及question非空
  2. 封装 JSON 请求数据包
  3. 通过 POST 方法发送至后端
  4. 后端处理：
    • 若含图片，调用 AI 图像识别模型分析作物状态
    • 结合问题文本与图片信息（如有），调用农业知识图谱生成回答
    • 整合结果并返回
  5. 前端解析数据，展示文字回答及图片分析详情

5. 天气查询接口（基于第三方 API 中转）​

接口功能​

通过调用第三方weatherAPI获取指定区域的实时及预报天气数据，支持基于农田位置自动定位或用户手动输入地址查询，满足农业生产对气象信息的需求。

请求方法​

GET

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
token用户身份验证令牌string是
location查询位置（可选）string否
farm_id农田 ID（可选）int否

请求示例​

{
  "type": "weather_query",
  "token": "用户令牌",
  "location": "江苏省镇江市",
  "farm_id": 123
}

返回值​

json_ret：包含以下气象数据

  • 基础信息：地区名称、查询时间
  • 实时天气：温度、湿度、天气状况（晴 / 雨等）、风力风向
  • 预报信息（未来 3 天）：最高 / 最低温度、天气状况

后端处理流程​

  1. 验证token有效性，确认location或farm_id至少有一个非空
  2. 封装 JSON 请求数据包
  3. 通过 GET 方法发送至后端（因第三方 API 多支持 GET，且位置参数便于拼接）
  4. 后端处理：
    • 若仅提供farm_id，从数据库查询该农田的location
    • 调用weatherAPI（如免费接口https://api.weatherapi.com），传入位置参数
    • 中转并格式化第三方返回的天气数据
  5. 前端接收数据，展示实时天气及预报图表
