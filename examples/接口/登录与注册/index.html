登录与注册

1. 注册账户接口​

接口功能​

提交注册账户请求信息，返回注册结果

请求地址​

POST /api/register

请求头​

请求头请求内容说明
AuthorizationBasic secretkey访问token
Content-Typeapplication/json请求方式

请求参数​

字段名字段说明字段类型是否必须
type数据包类型string是
name用户名string是
pwd密码string是
email邮箱地址string是

请求示例​

{
  "type": "register",
  "name": "testuser",
  "pwd": "password123",
  "email": "test@example.com"
}

响应示例​

成功响应：

{
  "code": "200",
  "message": "注册成功",
  "data": {
    "ret": true
  }
}

失败响应：

{
  "code": "400",
  "message": "邮箱格式不正确",
  "data": {
    "ret": false
  }
}

响应参数说明​

接口返回码接口返回描述
200注册成功
400请求参数异常
401授权失败
500系统异常

2. 登录账户接口​

接口功能​

提交登录账户请求，返回登录结果

请求地址​

POST /api/login

请求头​

请求头请求内容说明
AuthorizationBasic secretkey访问token
Content-Typeapplication/json请求方式

请求参数​

字段名字段说明字段类型是否必须
account用户名或邮箱string是
pwd密码string是
captcha图形验证码（可选）string否

请求示例​

{
  "account": "testuser@example.com",
  "pwd": "encrypted_password",
  "captcha": "ABCD"
}

响应示例​

成功响应：

{
  "code": "200",
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user_info": {
      "user_id": 12345,
      "username": "testuser",
      "email": "test@example.com"
    }
  }
}

失败响应：

{
  "code": "401",
  "message": "用户名或密码错误",
  "data": null
}

响应参数说明​

接口返回码接口返回描述
200登录成功
400请求参数异常
401认证失败
500系统异常

3. 验证码接口​

3.1 发送验证码​

接口功能​

向指定邮箱发送验证码

请求地址​

POST /api/captcha/send

请求头​

请求头请求内容说明
AuthorizationBasic secretkey访问token
Content-Typeapplication/json请求方式

请求参数​

字段名字段说明字段类型是否必须
type验证码类型int是
email邮箱地址string是

请求示例​

{
  "type": 1,
  "email": "test@example.com"
}

响应示例​

成功响应：

{
  "code": "200",
  "message": "验证码已发送",
  "data": null
}

3.2 验证验证码​

接口功能​

验证用户输入的验证码是否正确

请求地址​

POST /api/captcha/verify

请求头​

请求头请求内容说明
AuthorizationBasic secretkey访问token
Content-Typeapplication/json请求方式

请求参数​

字段名字段说明字段类型是否必须
captcha用户输入验证码string是
email邮箱地址string是
type验证码类型int是

请求示例​

{
  "captcha": "123456",
  "email": "test@example.com",
  "type": 1
}

响应示例​

成功响应：

{
  "code": "200",
  "message": "验证成功",
  "data": {
    "ret": true
  }
}

失败响应：

{
  "code": "400",
  "message": "验证码错误",
  "data": {
    "ret": false
  }
}

响应参数说明​

接口返回码接口返回描述
200验证成功
400验证码错误或已过期
401授权失败
500系统异常

4. 修改密码接口​

接口功能​

通过验证码验证修改账户密码

请求地址​

POST /api/password/reset

请求头​

请求头请求内容说明
AuthorizationBasic secretkey访问token
Content-Typeapplication/json请求方式

请求参数​

字段名字段说明字段类型是否必须
captcha验证码string是
email邮箱地址string是
pwd新密码string是

请求示例​

{
  "captcha": "123456",
  "email": "test@example.com",
  "pwd": "new_encrypted_password"
}

响应示例​

成功响应：

{
  "code": "200",
  "message": "密码修改成功",
  "data": {
    "ret": true
  }
}

失败响应：

{
  "code": "400",
  "message": "验证码无效",
  "data": {
    "ret": false
  }
}

响应参数说明​

接口返回码接口返回描述
200密码修改成功
400验证失败
401授权失败
500系统异常

全局响应状态码​

状态码说明
200请求成功
400请求参数异常
401授权失败
403禁止访问
404资源不存在
500服务器内部错误
